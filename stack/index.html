My AI Stack

Every Tool I Use and Why — As of 2026

A stack audit I do every few months. Here's what's in, what's out, and the honest take on each.

Core AI

Claude Max (Anthropic)

$100/mo

My primary reasoning and writing collaborator. The context window (200K tokens) and Claude Code changed how I work more than any other tool. Would be last to cut.

ChatGPT Plus (OpenAI)

$20/mo

Primarily for DALL-E 3 image generation and the mobile voice interface. Use it less than 2024 — Claude has pulled ahead for my main use cases.

Gemini Advanced (Google)

$20/mo (bundled)

Google Workspace integration is the value — summarizing email threads in Gmail, Slides drafting from docs. The integration beats the standalone model quality argument.

Development & Automation

Cursor Pro

$20/mo

All code editing. Replaced VS Code completely. The multi-file Composer and codebase Q&A are genuinely useful daily. Recommended for anyone who writes code but isn't a full-time engineer.

Modal

~$40/mo avg

Serverless Python for scheduled jobs and automation pipelines. The DX is exceptional — infrastructure requirements defined in decorators. Most underrated tool in the stack.

Content & Publishing

HeyGen Creator

$89/mo

AI video avatar for LinkedIn and YouTube. Record audio, get synchronized video. ROI is clear: one session produces content that would take half a day of camera setup otherwise.

ElevenLabs Creator

$22/mo

Voice cloning for video content and audio summaries. Quality has improved dramatically — the robotic quality from 18 months ago is mostly gone.

Analytics

PostHog

Free

Product analytics for this site. Funnel analysis, session recording, A/B testing. Enterprise-grade on a generous free tier. The right tool for a solo creator who thinks like a PM.

Google Analytics 4

Free

Traffic sources, SEO performance, geographic distribution. GA4's reporting is worse than Universal Analytics but the Search Console integration is valuable.

APIs

Anthropic API

~$55/mo avg

Powering automation workflows — content processing, summarization pipelines, RAG systems for knowledge management.

OpenAI API

~$17/mo avg

Embedding generation (text-embedding-3-small) for RAG systems and occasional multimodal tasks.

Total Monthly Cost

~$408/month

That number sounds high until you account for what it replaces: a video production team, a developer for automation work, and dozens of hours of manual effort.
